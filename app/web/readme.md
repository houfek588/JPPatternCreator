# Webová aplikace JPPatternCreator

Tato složka obsahuje bezstavový Flask server (`server.py`) a moderní klientskou aplikaci v Reactu 19 s Tailwind CSS (`frontend/`).
Podrobnější dokumentaci naleznete v [docs/web_api.md](../../docs/web_api.md) a [docs/web_application_requirements.md](../../docs/web_application_requirements.md).
